# 👤 Cadastro de Usuários — Spring Boot

Aplicação backend desenvolvida em Java e Spring Boot para implementar um sistema de cadastro e gerenciamento de usuários. 
O projeto foi criado para colocar em prática conceitos de desenvolvimento de APIs REST, arquitetura em camadas, persistência de dados e operações CRUD, utilizando tecnologias do ecossistema Spring.

O projeto faz parte da minha evolução no desenvolvimento backend com Java, aplicando conceitos estudados em uma aplicação prática e estruturada.

## 🚀 Tecnologias

- ☕ Java
- 🍃 Spring Boot
- 🗄️ Spring Data JPA
- 🌐 API REST
- 🛠️ Maven
- 🔧 Git & GitHub

## 🧠 Conceitos praticados

- Desenvolvimento de APIs REST
- Criação e gerenciamento de usuários
- Arquitetura em camadas
- Controllers, Services e Repositories
- Persistência de dados
- Mapeamento de entidades com JPA
- Requisições HTTP
- JSON
- Operações CRUD

## 🎯 Objetivo

Praticar o desenvolvimento **backend com Java e Spring Boot**, aplicando conceitos de APIs REST, persistência de dados e organização de aplicações em uma estrutura próxima à utilizada em projetos reais.

## 📚 Aprendizado

Este projeto faz parte da minha evolução no ecossistema **Java + Spring Boot**, servindo como prática para projetos backend mais completos e para o desenvolvimento de APIs.
